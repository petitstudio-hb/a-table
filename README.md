# Cabasito (anciennement A table)

Comparateur de supermarchés basé sur mes courses habituelles : dans quel magasin mon panier coûte-t-il le moins cher ?

- Cocher les produits de sa course et voir l'économie par magasin.
- Saisir des prix relevés en magasin (gardés dans le navigateur).

Site statique en HTML, CSS et JavaScript, sans dépendance. Les prix proviennent de relevés personnels. À terme, ils viendront aussi d'[Open Prices](https://prices.openfoodfacts.org).
